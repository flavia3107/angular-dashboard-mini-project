# 📋 Angular Components & Templates Practice

This project is part of the **Angular - The Complete Guide (2025 Edition)** Udemy course.  
It focuses on practicing **Angular components and templates** by building a small app that showcases their interaction.

---

## 📌 Features

- Creation and organization of **Angular components**  
- Linking of **templates** and **styles**  
- Use of **data binding** and **built-in directives** (`*ngIf`, `*ngFor`, etc.)  
- Display of dynamic data and **responsive layout**  

---

## 🛠️ Tech Stack

- **Languages**: TypeScript, HTML, CSS  
- **Framework**: Angular 16  
- **Tools**: VS Code, Git, GitHub  

---

## 🎯 Learning Objectives

✅ Practice **Angular component creation** and structure  
✅ Work with **component communication**  
✅ Implement **data binding** and **directive usage**  
✅ Build a small **interactive app** to apply core concepts
